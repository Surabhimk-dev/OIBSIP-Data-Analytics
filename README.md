# OIBSIP Data Analytics Projects

This repository contains my Data Analytics projects completed as part of the Oasis Infobyte Internship Program.

## Projects

### 1. Retail Sales EDA

Exploratory Data Analysis of retail sales data to understand sales, profit, categories, regions, and other business patterns.

**Tools Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

**Key Areas:**
- Data cleaning
- Exploratory data analysis
- Sales analysis
- Profit analysis
- Category and regional analysis
- Data visualization

Project folder: `Retail-Sales-EDA`

### 2. Customer Segmentation Analysis

Customer segmentation using RFM analysis and K-Means clustering to identify different groups of customers based on their purchasing behavior.

**Tools Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

**Key Areas:**
- Data cleaning
- RFM analysis
- Feature standardization
- Elbow Method
- K-Means clustering
- Customer segmentation
- Cluster visualization
- Marketing recommendations

Project folder: `Customer-Segmentation`

---

**Tools Used:**
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

**Key Areas:**

- Duplicate removal
